Welcome to Omarchy!

              
Omarchy is an omakase Linux distribution based on Arch, the tiling window manager Hyprland, and the desktop construction-kit Quickshell.

Install

          
One Omarchy package includes both guides, all narration, and desktop integration.

        


        

          
    
            
  1. 
              01
              
    
                
    Update Omarchy and install
    
                
    Run these commands in a terminal. Omarchy installs Learn Omarchy and its required dependencies.
    
                
    
                  
    install
    
                  
    $ omarchy update
$ omarchy pkg add learn-omarchy
    
                
    
              
    
            
    2. 
            
  2. 
              02
              
    
                
    Launch Learn Omarchy
    
                
    Open Apps with the shortcut, type Learn Omarchy, and press Enter.
    
                
    
                  Super+Space
                
    
                
    
                  Or launch it from a terminal
                  
    
                    
    launch
    
                    
    $ learn-omarchy
    
                  
    
                
    
              
    
            
    3. 
          

          

            

              
Update
omarchy update installs future Learn Omarchy releases with your other system updates.

              
Remove
learn-omarchy --uninstall removes the package and its managed integration. Progress is kept.

            

          

        


        

          Build from a GitHub checkout instead
          
Use this only if you cannot download the package and have a trusted checkout.

          

            
from source

            
$ sudo pacman -S --needed base-devel git nodejs
$ git clone https://github.com/DanWahlin/learn-omarchy.git
$ cd learn-omarchy
$ node tools/prepare-checkout-package.mjs --output release-work/local
$ cd release-work/local
$ makepkg --syncdeps --install
