Learn Omarchy: shortcut reference

Omarchy 4.0.3 defaults. Reviewed 2026-09-11 against the versioned sources below. Reference entries cover all 17 lessons and 101 activities.

Super is the Windows-logo key, or Command on a Mac keyboard; Alt is Option on a Mac keyboard. Return means Enter. Hold chord keys together. Entries marked Press in order are separate key presses, not held chords; Workflow entries describe menu paths or procedures.

MINUS and EQUAL name the two physical keys to the left of Backspace (codes 20 and 21), regardless of their printed labels. COMMA means the comma key.

Outside the guided app, shortcuts affect your real focused window and desktop, not just lesson-created windows. Save your work, use disposable windows, and inspect notifications before invoking them. Super + K shows current bindings; Enter or clicking a result executes it. Custom bindings may differ.

Workflow: COURSE: Welcome and lesson controls [18]
Replay Welcome, choose a topic, and use Practice to revisit activities. Help demonstrates; Skip leaves an activity for later.These are Learn Omarchy course controls, not default Omarchy shortcuts. Introduced content is not proof of hands-on practice.

Omarchy tour

Workflow: Desktop bar and Super key [3] [1]
The bar provides workspaces, clock and system controls. Super is the Windows-logo key, or Command on a Mac keyboard.
Workflow: Bar > Workspaces [3] [2]
Each workspace holds its own windows. The active marker can be an icon rather than a number; switching keeps windows open.
SUPER + 2 [12]
Switch to workspace two without moving or closing its windows.
SUPER + 1 [12]
Switch to workspace one.
Workflow: Bar > Clock [3]
Click the clock for the calendar. Hover for quick tools such as reminders and recording; weather appears when enabled.
Workflow: Bar > Status indicators [3]
Select network, Bluetooth, audio or power indicators to inspect controls. Available indicators depend on hardware and bar settings.
SUPER + SPACE [13]
Open the Omarchy menu for apps, settings and system tools.
Workflow: Bar > Omarchy icon [3]
Click the Omarchy icon to open the same menu without a keyboard shortcut.

Menus and apps

SUPER + SPACE [13]
Open the Omarchy menu for apps, settings and system tools.
SUPER + ALT + SPACE [13]
Open Apps to search launchable applications, not every installed package. Alt is Option on a Mac keyboard.
Workflow: Apps > Search > Launch [2] [18]
Open Apps, type Terminal or Ghostty, select the installed terminal and press Enter. In the COURSE, choose Start search first, then close the newly opened terminal to finish.Escape clears typed search text; press again to close, or once if empty. Check the focused window before closing anything.
SUPER + W [12]
Close the focused window.Save work first. This is not limited to the terminal opened for practice.
SUPER + K [1]
Open the shortcut guide and type to filter bindings.Enter or clicking a result runs that shortcut, potentially closing a window or locking the screen. Read without activating unfamiliar results.

Everyday apps

SUPER + RETURN [14]
Open a terminal for commands. Return is the Enter key on most keyboards.
SUPER + W [12]
Close the focused window.Save work and verify focus first; any focused app can close, not only a practice terminal or file manager.
SUPER + SHIFT + RETURN [14] [9]
Launch the configured browser. Browser settings determine whether a new window opens.
SUPER + SHIFT + F [14]
Open the file manager to browse folders and documents.

Windows

SUPER + RETURN [14] [2]
Open a terminal. Tiling fits additional windows into the available workspace without overlap.
SUPER + J (optional activity) [12]
Toggle the split direction within the dwindle layout; repeat to toggle back.Needs tiled windows in dwindle. This does not switch workspace layouts or provide the same split behavior in floating, scrolling or custom layouts.
ALT + TAB [12]
Cycle focus through windows on the active workspace. Focus determines which window receives keyboard input.Includes your existing windows, not just practice windows.
SUPER + T [12]
Toggle the focused window between floating and tiling. Repeat to return it to the tiled layout.
SUPER + EQUAL [12]
Resize horizontally by a 100-pixel step using physical keycode 21, immediately left of Backspace (normally equals on US keyboards).No Shift or Plus key is needed. Physical position, window size limits and the movable tiled edge determine the result.
SUPER + MINUS [12]
Resize horizontally in the other direction by a 100-pixel step using physical keycode 20, two places left of Backspace (normally minus on US keyboards).These are physical keycodes, not character bindings. Tiled edges and size limits affect the result; reversing need not restore the exact size.
SUPER + SHIFT + EQUAL [12]
Resize height instead of width by a 100-pixel step.Use physical keycode 21, immediately left of Backspace, not a typed Plus character. Layout constraints still apply.
SUPER + SHIFT + MINUS [12]
Resize height in the other direction by a 100-pixel step.Use physical keycode 20, two places left of Backspace. Layout constraints still apply.
SUPER + ALT + EQUAL [12]
Use a finer 25-pixel horizontal resize step. Add Shift for height instead of width.Use physical keycode 21, immediately left of Backspace. Size limits and tiled edges can prevent resizing.
SUPER + ALT + MINUS [12]
Use a finer 25-pixel horizontal resize step in the other direction. Add Shift for height.Use physical keycode 20, two places left of Backspace. Size limits and tiled edges can prevent resizing.
SUPER + CTRL + EQUAL [12]
Use a larger 300-pixel horizontal resize step. Add Shift for height instead of width.Use physical keycode 21, immediately left of Backspace. Size limits and tiled edges can prevent resizing.
SUPER + CTRL + MINUS [12]
Use a larger 300-pixel horizontal resize step in the other direction. Add Shift for height.Use physical keycode 20, two places left of Backspace. Size limits and tiled edges can prevent resizing.
SUPER + F [12]
Toggle fullscreen for the focused window; repeat to leave fullscreen.
SUPER + ARROW [12]
Focus the neighboring window in the chosen direction: left, right, up or down.
SUPER + SHIFT + ARROW [12]
Swap the focused window with the adjacent window in the chosen direction.Changes both windows' positions, including existing work. Check focus and the neighbor first.
SUPER + W [12]
Close the focused window; remaining tiles reclaim its space.Save work first. The shortcut can close any focused window.

Return to the last workspace you visited.
SUPER + SHIFT + 2 [12]
Move the focused window to workspace two and follow it there. Also restores a visible, focused scratchpad window to that numbered workspace.Check focus first. A hidden scratchpad window is not the target; reveal it and select it before moving.

Switch to the next workspace.
SUPER + SHIFT + TAB [12]
Switch to the previous workspace.
SUPER + ALT + S [12]
Move the focused window to the scratchpad, a hidden workspace that can appear over your desktop.Verify which window has focus before stashing it.

SUPER + W [12]

Clipboard and Compose

SUPER + C [1] [19]
Copy selected text using Omarchy's shared copy shortcut, including in supported terminals.Replaces the current clipboard. Custom bindings and app support can differ.
SUPER + V [1] [19]
Paste the clipboard into the focused destination using Omarchy's shared paste shortcut.Check the destination first, especially terminals and sensitive fields. App support can differ.
SUPER + CTRL + V [4] [15]
Open clipboard history to search recent copies. Use arrow keys to highlight an entry or select with the mouse.History may contain private information. Escape clears search text, then closes when empty.
SHIFT + ENTER [15]
In clipboard history, copy the highlighted entry without pasting. Then focus the destination and paste once.
ENTER [15]
In clipboard history, activate the highlighted entry and attempt immediate paste into the previously focused app.Mouse activation also attempts paste. Behavior depends on the target app; use Shift+Enter for copy-only rather than assuming Enter just copies.
Workflow: COURSE: Clipboard practice [19]
Select and copy the first sample, then the newer sample. Open history, highlight the first note and use Shift+Enter. Click the destination and paste once; check it matches the first note.This exercise replaces your clipboard with harmless sample text.
Press in order: CAPS LOCK → m → s [16] [19]
Compose a smile (😄): tap and release Caps Lock, then press lowercase m, then lowercase s.Separate presses, not held together; no Shift. Caps Lock is Compose by default, but custom mappings may differ.
Press in order: CAPS LOCK → m → h [16] [19]
Compose a heart (❤️): tap and release Caps Lock, then press lowercase m, then lowercase h.Separate presses, not held together; no Shift. In COURSE practice, enter smile and heart in their respective fields; skip rather than changing custom mappings.

Capture

SUPER + CTRL + C [13] [5]
Open Capture for screenshots, recordings, color picking and text extraction. Use the menu if your keyboard has no Print key.
PRINT [5]
Start a screenshot with the frozen-screen picker; drag over the desired region. Alternatively search Screenshot in the Omarchy menu.Inspect for private content first. Screenshots save to the configured Pictures directory and clipboard.
Press in order: TAB → ENTER [5]
In the screenshot picker, use Tab to select a window, then Enter to capture the selected window.These are sequential presses in the picker, not a held chord. Check the selected window before capturing.
CTRL + ENTER [5]
In the screenshot picker, capture the full screen.Includes visible private windows and notifications; inspect before capturing.
ESCAPE [5] [19]
Cancel screenshot region selection without taking a capture.
Workflow: Screenshot notification > Edit [5]
Click the screenshot notification to open the captured image for editing.Verify it is the intended screenshot notification before invoking its action.
SUPER + ALT + COMMA [5] [13]
Invoke the latest notification's action; when it is the screenshot notification, open the screenshot editor.A different notification may launch an app or follow a link. Inspect the latest notification first.
Workflow: COURSE: Capture practice [19]
Select only the harmless card, inspect the saved image, copy its file path and add a label to the preview.The course uses its own capture tools. Preview annotation does not alter the saved image; nothing is uploaded.
ALT + PRINT [5] [13]
Open recording options, or stop an active recording. Choices: no audio; desktop audio; desktop + microphone audio; or desktop + microphone audio + webcam when available. Saved clips go to the configured Videos directory.Microphone includes desktop audio; webcam includes both. Review the region and recording indicator, know how to stop, and get permission before recording other people's voices or private content.
Workflow: COURSE: Record > Stop > Replay [19]
Select and review the animated card's region. Explicitly start a silent recording, record at least one second, stop your recording, then play the saved clip.This course-specific recorder uses no microphone or webcam and owns only its recording; it does not stop an existing recorder. This is separate from native recording options.
SUPER + CTRL + PRINT (optional activity) [6] [13]
Extract text from a selected screen region with OCR (optical character recognition).Recognition can make mistakes. Proofread against the source before using the text; avoid private regions.
Workflow: COURSE: OCR practice (optional activity) [19]
Select the sample text card, extract it, copy the recognized sample and paste it into the destination. Compare every word with the original.Requires slurp, grim and tesseract; course verification is a reviewed sample, not a guarantee of general OCR accuracy.
Workflow: Omarchy menu > QR Code (optional activity) [5] [6]
Search QR Code to select and decode a code already on screen, then inspect the decoded text.Decoding is not permission to open an unknown link.
Workflow: COURSE: QR practice (optional activity) [19]
Prepare the harmless QR sample, select and decode it, copy the result and paste it below to compare with the sample.The sample contains text, not a website; no link is opened. Requires qrencode, slurp, grim and zbarimg.

Apps and upkeep

Workflow: Omarchy menu > Install [7]
Search Install to find software packages. Prefer official packages; review community Arch User Repository (AUR) packages more closely.Installing can request your password and change the system. Inspect package details before confirming; no installation is needed to learn the menu.
Workflow: Omarchy menu > Remove [7]
Uninstall an unwanted package only after checking its name and the full removal list. Dependencies are software other apps need.Removal may affect other software. Cancel if you do not understand the proposed changes.
Workflow: Setup > Defaults [9] [14]
Choose which installed apps Omarchy launches by default. Open the Omarchy menu and search Defaults.Default changes affect future launches immediately. Installing an app and making it the default are separate decisions.
Workflow: Omarchy menu > Update [10]
Save work, review proposed changes and use the stable channel for everyday updates to Omarchy and its packages.Some installations create rollback snapshots before updates. Snapshots are not independent backups of personal files.
Workflow: Update > Hardware [10] [18]
Use targeted hardware restarts only when needed. Distinguish restarting a device or updating software from resetting its configuration.Network or audio restarts can interrupt calls, downloads and recordings. Back up custom settings under ~/.config before resets; do not edit packaged defaults under /usr/share/omarchy.

Open Display for text size, scale, supported brightness and multi-display enable/disable controls. Escape closes the panel.Changes apply immediately. Configure resolution separately under Setup > Monitors.
SUPER + ESCAPE [13]
Open System for lock, suspend, logout, reboot and shutdown.Inspect without selecting a disruptive action; save work before logging out, restarting or shutting down.
SUPER + CTRL + L (optional activity) [13] [19]

SUPER + O [12] [2]
Pop a tiled window out: float and pinStart tiled. Invoke again on the pinned pop-out to unpin and retile. Pop-out also resizes and centers; pinning keeps it visible across workspaces on its display. Already-floating or independently pinned windows can behave differently.
SUPER + L [12] [2]
Toggle workspace layout between dwindle and scrollingPersists a setting. A custom layout is not restored by toggling again. The saved setting is per-workspace; a custom layout switches to dwindle. Dwindle divides tiles; scrolling extends windows horizontally. This is not the dwindle split toggle.
Mouse gesture: SUPER + LEFT MOUSE DRAG [12]
Move a windowHold Super while dragging with the left mouse button, then release both. Start with a disposable floating window; on tiled windows, the layout determines the effect.

Resize a windowHold Super while dragging with the right mouse button, then release both. Start with a disposable floating window; tiled layout constraints affect resizing.
